# mygo 迁移：被移除功能说明（草稿）

本文件用于发布说明。迁移到 mygo 后，以下功能不再提供。升级不会删除任何已有数据。

## 已移除

### 内置浏览器（YoBrowser）与 Agent 浏览器自动化

- 侧边栏的浏览器标签页、地址栏和页面预览不再提供。
- Agent 不再拥有 `get_browser_status`、`load_url`、`cdp_send` 三个工具，也不再具备基于 CDP 的页面点击、脚本执行、DOM 检查和网页截图能力。
- 浏览器沙盒数据清理、浏览器会话数据导入（Chrome / Arc 配置）入口一并移除。
- 替代方式：需要查看网页时，链接会交给系统默认浏览器打开。Agent 仍可通过 `exec` 调用用户自带的命令行工具处理网页请求。

### 浮动按钮与悬浮聊天窗

- 桌面悬浮按钮、悬浮聊天窗不再提供。入口为主窗口和托盘图标。
- 设置项 `floatingButtonEnabled`、`floatingButtonBounds` 不再读取，历史值保留在设置存储中，不影响升级。

### computer use 的画中画预览

- computer use 的 PiP 预览窗口（含点击后自动刷新预览）不再提供。
- CUA 插件本身、其工具调用与截图分析保持不变。

### 登录方式调整（计划，尚未完成）

- 目标是将 GitHub Copilot 等 OAuth 登录改为系统浏览器授权并回到应用，不再使用应用内弹窗页面。当前迁移尚未完成；GitHub 的仓库外回调页仍需配合接入 deep link，纳入发布说明前必须完成实现与验收。

## 兼容性说明

- 历史会话中的浏览器工具调用记录仍会正常显示（工具名与结果文本保留），不会被删除或报错。
- 已停用的旧工具名会从会话的「已禁用工具」列表中自动清理。
- 数据库结构与用户配置格式不变。
